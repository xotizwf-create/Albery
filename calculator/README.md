# Публичный калькулятор Albery

Отдельный статический Vite-бандл для `https://www.m4s.ru/Калькулятор/`.

Калькулятор работает полностью в браузере: не вызывает API, не использует секреты и не
отправляет введённые значения на сервер. Сборка выполняется локально:

```text
npm ci
npm run lint
npm run build
```

На прод передаётся готовый `dist/`; Flask раздаёт его через отдельный публичный маршрут.
