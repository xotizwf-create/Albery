# Подключение аккаунта Авито — инструкция для человека

Подключить свой аккаунт Авито можно самому, разработчик для этого не нужен.

## Что нужно перед началом

- **Компьютер с обычным домашним интернетом.** Не сервер и не VPN: Авито не пускает
  адреса дата-центров, а вход из другой страны может закрыть аккаунт. Если у вас включён
  VPN — выключите его на время подключения.
- **Телефон с той симкой, что привязана к аккаунту Авито** — придёт код.
- Установленные `python` и зависимости проекта (`pip install -r requirements.txt`,
  затем `playwright install chromium`).
- Файл `~/.avito-profiles/.env` с двумя строками — их даёт владелец системы:

  ```
  ALBERY_BASE_URL=https://…
  AVITO_WORKER_TOKEN=…
  ```

  Токен общий для всех аккаунтов, поэтому давать его можно только тем, кому доверяете:
  его владелец технически может прочитать переписку любого подключённого аккаунта.

## Как подключить

Двойной клик по **`scripts/Подключить Авито.cmd`** — и дальше по подсказкам.

Либо из командной строки:

```bash
python scripts/avito_worker.py connect --label "Отдел закупок"
```

Мастер спросит название аккаунта (как подписать его в кабинете), сам придумает latin-код,
заведёт запись в системе и откроет окно браузера. В окне вы проходите капчу, входите и
вводите код из SMS — программа ждёт до 15 минут и проверяет сама.

**Аккаунт включается только после подтверждённого входа.** Подтверждение честное: система
спрашивает у самого Авито id вошедшего аккаунта. Страницу «Доступ ограничен: проблема с IP»
за успешный вход она не примет — на этом уже обжигались 21.08.2026.

## После подключения

Зеркало запускается так:

```bash
python scripts/avito_worker.py mirror --account <код>
```

Чтобы оно поднималось само при входе в систему — задача в планировщике Windows
(«Albery - зеркало Авито»); для нового аккаунта скопируйте её, поменяв код в аргументах.

## Что делать, если не вышло

| Что видно | Что это значит | Что делать |
|---|---|---|
| «Доступ ограничен: проблема с IP» и капча не проходится | Авито считает сессию подозрительной | Выключить VPN, перезапустить роутер, попробовать позже |
| Код из SMS не приходит | Номер не привязан к этому аккаунту | Проверить, та ли симка |
| Окно закрылось само | Мастер завершился по времени | Запустить заново, окно не закрывать |
| «Не удалось завести аккаунт» | Не тот токен или адрес в `.env` | Взять актуальные у владельца |

## Важное про переписку

Зеркало приносит в кабинет **только рабочие переписки** — те, что завела сама система
(«написать первым» и ответы на них). Личные чаты аккаунта в кабинет не попадают: граница
стоит на входе, в `ingest_inbound`. Это сделано 20.08.2026 после того, как в рабочий
кабинет попала личная переписка владельца — аренда квартир, продавцы подписок, репетитор.
